# Player RJP Stream V0.2

- MP4/WebM/outros formatos que o browser suporte: HTML5 `<video>`.
- HLS `.m3u8`: HLS nativo quando disponível; caso contrário HLS.js 1.7.2.
- DASH `.mpd`: dash.js 5.2.1.
- O suporte final depende do codec e das capacidades do dispositivo.
- Não existe bypass de DRM.
- Samsung/LG mais antigas podem precisar de uma build específica com bibliotecas compatíveis com o respetivo motor web.
