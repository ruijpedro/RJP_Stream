# Configuração rápida RJP Stream V1.5

1. Compilar/instalar o APK do artifact `RJP-Stream-V1.5-Android`.
2. Abrir **Fontes** e importar uma lista local ou usar **Analisar URL**.
3. Para M3U/JSON, escolher os canais/categorias antes de importar.
4. Configurar EPG/Google Drive se necessário.
5. Opcionalmente importar uma configuração WireGuard no Android/Android TV.
