# IPTV Free · RJP Stream V1.6

Menu **Fontes** → **IPTV Free** → escolher fonte → pré-visualizar → selecionar → importar.

Fontes públicas incluídas:
- IPTV-org Sports: https://iptv-org.github.io/iptv/categories/sports.m3u
- M3UPT Portugal: https://m3upt.com/iptv
- Free-TV: https://raw.githubusercontent.com/Free-TV/IPTV/master/playlist.m3u8

As fontes são externas, não têm garantia de disponibilidade. A importação não contorna DRM ou restrições geográficas. A pré-visualização e leitura de playlists remotas podem ser bloqueadas por CORS no browser, enquanto Android dispõe do fallback nativo já incluído. O EPG M3UPT pode ser inserido separadamente em Fontes → EPG, se necessário.
