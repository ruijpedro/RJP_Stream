# Identidade visual RJP Stream V1.6

- Ícone de aplicação: `assets/rjp-stream-icon.png` e `assets/icons/`.
- Símbolo/logótipo com transparência: `assets/rjp-stream-logo.png`.
- Android: `assets/icon-kitchen/android/res/`, usado por `scripts/patch-android.mjs`.
- WebApp/PWA: `manifest.webmanifest`, `assets/apple-touch-icon.png`, `assets/favicon.ico`.

Para criar uma nova APK, executar o workflow de Android no GitHub. Pode ser necessário eliminar e voltar a adicionar o atalho PWA para limpar o ícone em cache.
