# RJP Stream V1.7

No menu Fontes → IPTV Free: listas desportivas e de automobilismo; apenas streams autorizados.

Se surgir manifestLoadError, o erro pode ser causado por servidor desligado, CORS, geobloqueio ou autenticação. O diagnóstico apresenta HTTP quando disponibilizado. Nenhuma melhoria remove DRM, autorização ou geobloqueio.

O workflow do GitHub Actions produz um único APK debug na pasta `apk/debug` do artefacto. Não há AAB.

A reprodução real e o APK devem ser testados num equipamento; este ZIP não contém uma APK pré-compilada.
